**验收标准**：

- [ ] 棋盘 10×20 渲染正确，当前方块与已锁定方块颜色区分
- [ ] Next 面板显示 ≥ 3 个预览
- [ ] HUD（分数/等级/行数）实时更新，且不引起棋盘重渲染
- [ ] 临时按钮（左/右/旋转/软降/硬降）全部可用
- [ ] 用临时按钮可完成完整一局：开始 → 玩 → Game Over
- [ ] Game Over 后可重新开始
- [ ] rAF 循环在 JS 线程无长时间阻塞（肉眼无卡顿）

## M4 — 双端真机完整闭环（Phase 4 收尾）

**交付内容**：手势操控 + 暂停/恢复 + 最高分持久化 + 双端适配，形成完整产品闭环。

**验收标准**：

- [ ] iOS 真机 + Android 真机（或模拟器）均可手势玩一局
- [ ] 手势：左右滑移动、下滑软降、快速下滑硬降、点击旋转，误触率可接受
- [ ] 暂停 → 恢复：状态完整，无跳帧/时间漂移
- [ ] App 切后台自动暂停，回前台保持暂停待确认
- [ ] Android 返回键弹出暂停确认，不直接退出
- [ ] 最高分持久化：杀进程重启后仍显示
- [ ] 设置页（幽灵方块开关、灵敏度）可切换且持久化
- [ ] SafeArea：双端无遮挡
- [ ] Phase 4 问题记录表无未解决的 P0 问题
